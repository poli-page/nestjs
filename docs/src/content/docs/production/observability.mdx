title: Observability
description: Log and trace Poli Page requests from NestJS with the SDK's onRequest, onResponse, onRetry and onError callbacks.
---

The module passes four optional callbacks straight to the SDK client: `onRequest`, `onResponse`, `onRetry` and `onError`. They are the integration's only observability hooks; wire them to Nest's `Logger`, your metrics or your tracer in the module options.

## The callbacks

- `onRequest(event)` fires before each HTTP request leaves: `event.method`, `event.url`, `event.attempt`.
- `onResponse(event)` fires once a 2xx answer has been read in full: `event.status`, `event.durationMs`, `event.requestId`.
- `onRetry(event)` fires when the SDK decides to retry: `event.attempt`, `event.delayMs`, and `event.reason`, the `PoliPageError` that caused it.
- `onError(err)` fires when a request fails for good, after the retries: `err` is the `PoliPageError`.

The SDK does not await the callbacks, and they cannot change the request. Their event types, `RequestEvent`, `ResponseEvent` and `RetryEvent`, are re-exported from `@poli-page/nestjs`.

## Use other providers

The callbacks are module options, so `forRootAsync` can build them from injected providers: a metrics service, a tracer, or `ConfigService` to turn logging on per environment.

## Request IDs

`err.requestId` and `event.requestId` are the API's `x-request-id`. Log them: they are what Poli Page support asks for. The global exception filter also sends `requestId` in the JSON body of every error answer.

## Example

```ts
// src/app.module.ts
import { Logger, Module } from '@nestjs/common'
import { PoliPageModule } from '@poli-page/nestjs'

const logger = new Logger('PoliPage')

@Module({
  imports: [
    PoliPageModule.forRoot({
      apiKey: process.env.POLI_PAGE_API_KEY!,
      onRequest: (event) => logger.debug(`${event.method} ${event.url} attempt=${event.attempt}`),
      onResponse: (event) => logger.log(`${event.status} in ${event.durationMs}ms requestId=${event.requestId ?? '-'}`),
      onRetry: (event) => logger.warn(`retry in ${event.delayMs}ms: ${event.reason.code}`),
      onError: (err) => logger.error(`${err.code} requestId=${err.requestId ?? '-'}: ${err.message}`),
    }),
  ],
})
export class AppModule {}
```
